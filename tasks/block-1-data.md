# Блок 1. Данные, операции, логика

После уроков 5–10. Ты знаешь: двоичную систему, примитивные типы и их диапазоны, литералы, переменные и `final`,
арифметику `+ - * / %`, составные операции `+=`, `++`, приведение `(double)`, сравнения и логические `&&`, `||`, `!`.

Важно для этого блока:

- **Один `println` — одно значение.** Склеивать текст с числами (`"Сумма: " + sum`) мы ещё не умеем —
  это будет в уроке 13. Поэтому каждое число выводи отдельной строкой.
- **`if` ещё нет.** Все задачи решаются арифметикой и логическими выражениями.
- **Ввод с клавиатуры** — готовым фрагментом `Scanner`, см. README. В заготовках он уже есть.

Решения пиши в заготовках `src/block1/TaskXX.java`.

## Задача 1.9 ★★ Логика на бумаге

*Урок 10*

**Часть А.** Предскажи вывод (как в задаче 1.4), потом запусти и сверь:

```java
int x = 7;
int y = -3;
System.out.println(x > 0 && y > 0);
System.out.println(x > 0 || y > 0);
System.out.println(!(x == 7));
System.out.println(x % 2 == 0);
System.out.println((x > 5 && x < 10) || y == 0);
System.out.println(x != y && !(y < 0));
System.out.println(!(x > 0) || !(y > 0));
```

**Часть Б.** В комментариях составь таблицы истинности, как в уроке (0 — false, 1 — true):

1. `a && !b`
2. `(a || b) && !(a && b)`
3. `a && (b || c)` — здесь три переменные, значит, строк в таблице будет 8.

Посмотри на вторую таблицу: когда выражение даёт 1? Опиши словами, что это за операция.

**Часть В.** Проверь вторую таблицу кодом: заведи `boolean a` и `boolean b`, выведи значение выражения,
меняй значения `a` и `b` и запускай заново, пока не проверишь все 4 строки.
