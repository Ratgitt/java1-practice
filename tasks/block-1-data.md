## Задача 1.3 ★★ Предскажи вывод

*Уроки 8–9*

Скопируй код в `main`. **До запуска** напиши рядом с каждым `println`, что он выведет. Потом запусти; где ошибся —
допиши, почему.

```java
System.out.println(7 / 2);
System.out.println(7 / 2.0);
System.out.println((double) (7 / 2));
System.out.println(17 % 5);
System.out.println(2 + 3 * 4);

int a = 5;
int b = a;
a = 12;
System.out.println(b);

int x = 10;
x += 3;
x *= 2;
x--;
x %= 4;
System.out.println(x);

double d = 9 / 2;
System.out.println(d);
```

## Задача 1.6 ★★ Условия

*Уроки 9–10*

Дано целое `x`. Выведи `true` или `false` для каждого утверждения — пять строк:

1. `x` от 10 до 20 включительно;
2. `x` не от 10 до 20;
3. `x` чётное;
4. `x` делится на 3, но не на 5;
5. `x` — двузначное положительное.

**Пример**

```text
> 15
true
false
false
false
true
```

## Задача 1.7 ★★★ Счастливый билет

*Уроки 9–10*

Номер билета — шесть цифр, ведущие нули не вводятся (`001010` → `1010`). Билет счастливый, если сумма первых трёх
цифр равна сумме последних трёх. Выведи `true` или `false`.

**Пример 1**

```text
> 123321
true
```

**Пример 2**

```text
> 1010
true
```
