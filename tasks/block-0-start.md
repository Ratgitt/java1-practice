# Блок 0. Первая программа

После уроков 1–4. Пока ты умеешь главное: создать класс с `main` и выводить строки через `System.out.println("...")`.
Этого уже хватает, чтобы убедиться, что всё установлено и работает, и привыкнуть к IDEA.

Решения пиши в заготовках `src/block0/TaskXX.java`.

---

## Задача 0.1 ★ Визитка

*Урок 4*

Выведи на экран визитку о себе — четыре строки:

1. как тебя зовут;
2. из какого ты города;
3. чем увлекаешься;
4. зачем тебе программирование.

Каждая строка — отдельный `System.out.println`. Например:

```plain
Меня зовут Алексей
Я из Казани
Люблю футбол и шахматы
Хочу делать свои игры
```

Текст свой, вывод у каждого будет разный.

## Задача 0.3 ★ Почини программу

*Урок 4*

Вот программа с ошибками. Скопируй строки из `main` в свою заготовку `Task03` и исправь их так, чтобы программа
запустилась.

```java
System.out.println("Hello, Java")
system.out.println("Это моя вторая программа");
System.out.printn("Ура!");
System.out.println('Скоро будет интересно');
```

IDEA подчеркнёт ошибки красным. Наведи мышку на каждую ошибку и прочитай сообщение. Бывает, что одна ошибка
даёт несколько сообщений, а после исправления одной появляется новая — это нормально, исправляй по очереди. Над каждой исправленной
строкой напиши комментарий `//`: что сообщила IDEA и что ты исправил. Например:

```java
// IDEA: ... — забыл ...
System.out.println("Hello, Java");
```

После исправления программа должна вывести:

```text
Hello, Java
Это моя вторая программа
Ура!
Скоро будет интересно
```
