# Блок 4. Циклы и рекурсия

После уроков 20–23. Ты знаешь: циклы `while`, `do-while` и `for`, `break` и `continue`, цикл по символам `char`,
шаг вроде `/= 10`, переменную-накопитель (сумма, произведение), рекурсию — функцию, которая вызывает саму себя.
Всё из прошлых блоков тоже в ходу: ветвления, `switch`, функции.

Важно для этого блока:

- **У каждого цикла должна быть понятная причина закончиться.** Если программа зависла — останови её красной
  кнопкой Stop в IDEA и подумай, почему условие цикла никогда не становится ложным.
- **Обходись без `break` и `continue`**, как советует автор: пусть цикл останавливает его условие. Ранний `return`
  из функции — можно.
- **Если в условии дана сигнатура функции — напиши функцию ровно с ней.** Функция возвращает результат, печатает `main`
  (кроме задач, где сказано иначе).
- **Печатать без перехода на новую строку мы ещё не умеем** (это будет в уроке 27). Если нужно вывести строку из
  нескольких кусков — собери её в переменную `String` и выведи одним `println`.

Решения пиши в заготовках `src/block4/TaskXX.java`.

## Задача 4.3 ★★ Почему программа зависла

*Уроки 20–21*

Замени всё содержимое заготовки `Task03` этим кодом и запусти.

```java
package block4;

public class Task03 {

    public static void main(String[] args) {
        System.out.println(sumOdd(7));
        System.out.println(sumOdd(10));
        printCountdown(3);
        System.out.println(countZeros(10203));
        System.out.println(countZeros(5));
    }

    // сумма нечётных чисел от 1 до n включительно
    public static int sumOdd(int n) {
        int sum = 0;
        for (int i = 1; i != n; i += 2) {
            sum += i;
        }
        return sum;
    }

    // печатает n, n-1, ..., 1
    public static void printCountdown(int n) {
        while (n > 0); {
            System.out.println(n);
            n--;
        }
    }

    // сколько нулей в записи числа
    public static int countZeros(int number) {
        int count = 0;
        while (number > 0) {
            if (number % 10 == 0) {
                count++;
            }
        }
        number /= 10;
        return count;
    }
}
```

Программа выведет одно число и зависнет — останови её кнопкой Stop. В каждой из трёх функций ровно одна ошибка.
Найди и исправь их, не переписывая функции заново. Над каждой исправленной строкой напиши в комментарии, почему цикл
не заканчивался (или считал неверно).

Обрати внимание на первое выведенное число: программа не зависла на нём, но верно ли оно?

После исправления программа должна вывести:

```text

25
3
2
1
2
0
```

## Задача 4.12 ★★★ Рекурсия без выхода

*Урок 23*

Замени всё содержимое заготовки `Task12` этим кодом и запусти.

```java
package block4;

public class Task12 {

    public static void main(String[] args) {
        System.out.println(power(2, 10));
        System.out.println(power(7, 0));
        System.out.println(countDigits(4096));
        System.out.println(countDigits(0));
    }

    public static long power(int base, int exponent) {
        if (exponent == 1) {
            return base;
        }
        return base * power(base, exponent - 1);
    }

    public static int countDigits(int number) {
        if (number == 0) {
            return 0;
        }
        return 1 + countDigits(number / 10);
    }
}
```

Программа выведет `1024` и упадёт с ошибкой `StackOverflowError`. Что это значит: каждый вызов функции, который ещё
не закончился, занимает немного памяти. Если функция вызывает себя снова и снова и ни один вызов не заканчивается,
эта память (она называется *стек*) переполняется, и Java аварийно останавливает программу.

1. Разверни на бумаге вызов `power(7, 0)`: какие вызовы происходят дальше? Почему ни один из них не возвращает
   значение? Ответ напиши в комментарии.
2. Исправь `power` так, чтобы она работала для любого `exponent` от 0 и больше.
3. После этого программа дойдёт до `countDigits`. Она не упадёт, но одна из строк будет неверной. Найди её и исправь
   функцию для любого `number` от 0 и больше. Рекурсию оставь — циклов в этих функциях быть не должно.
4. В комментарии ответь: при каких аргументах исправленная `power` всё равно упадёт?

После исправлений программа должна вывести:

```text
1024
1
4
1
```
