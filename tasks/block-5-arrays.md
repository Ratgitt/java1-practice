# Блок 5. Массивы

После уроков 25–28. Ты знаешь: одномерные массивы (`int[]`, `{…}`, `new int[n]`, `length`, индексы с нуля, значения
по умолчанию), двумерные и «рваные» массивы, `null`-строки и пустой массив `{}`, обход обычным `for` и for-each,
вложенные циклы, `System.out.print` и пустой `System.out.println()`, `Math.min`/`Math.max`, обмен через `temp`,
функции, которые принимают массив.

Важно для этого блока:

- **`Arrays` не используем** — в курсе его не проходили. Массив печатай сам: циклом или своей функцией. Числа в строке — через пробел: `System.out.print(value + " ")`,
  потом `System.out.println()`. Лишний пробел в конце строки не важен.
- **Ввод массива.** Если пользователь вводит `n`, а затем `n` чисел — создай `new int[n]` и заполни его в цикле
  через `scanner.nextInt()`. Числа можно вводить в одну строку через пробел: `nextInt()` всё равно берёт их по одному.
- **Пустой массив.** В каждой задаче сказано, может ли массив быть пустым и что тогда выводить. Если не сказано —
  массив гарантированно не пустой.

## Задача 5.4 ★★ Предскажи вывод: один массив — два имени

*Уроки 26–28*

Скопируй в заготовку **целиком** — `main` и две функции под ним. Как в задаче 5.1: предскажи вывод каждого `println`
в комментариях, запусти, сверь.

```java
public static void main(String[] args) {
    int a = 5;
    int b = a;
    b = 10;
    System.out.println(a);

    int[] first = {1, 2, 3};
    int[] second = first;
    second[0] = 100;
    System.out.println(first[0]);
    System.out.println(second[0]);

    int number = 1;
    addOne(number);
    System.out.println(number);

    int[] numbers = {1, 2, 3};
    addOneToAll(numbers);
    System.out.println(numbers[0] + " " + numbers[1] + " " + numbers[2]);

    for (int value : numbers) {
        value = 0;
    }
    System.out.println(numbers[0] + " " + numbers[1] + " " + numbers[2]);

    int[][] grid = {{1, 2}, {3, 4}};
    int[] row = grid[1];
    row[0] = 9;
    System.out.println(grid[1][0]);

    for (int[] line : grid) {
        line[1] = 0;
    }
    System.out.println(grid[0][1] + " " + grid[1][1]);
}

public static void addOne(int x) {
    x++;
}

public static void addOneToAll(int[] values) {
    for (int i = 0; i < values.length; i++) {
        values[i]++;
    }
}
```

**Прочитай после запуска.** Переменная типа `int` хранит само число. А переменная-массив хранит только «адрес», где
массив лежит в памяти, — тот самый `[I@…`, который печатается вместо элементов (урок 26). Поэтому `second = first`
копирует адрес, а не элементы: обе переменные смотрят на **один и тот же** массив. С функциями так же: параметр
`int x` получает копию числа, а параметр `int[] values` — адрес массива, и функция меняет элементы прямо в нём.
Подробно про адреса и память — в следующем курсе.

Сверь это со своими предсказаниями и ответь в комментариях:

1. Почему `addOne` не изменила `number`, а `addOneToAll` изменила `numbers`?
2. В уроке 27 автор назвал for-each «только для чтения». Посмотри на две последние печати: всегда ли это так?
   Когда через for-each массив изменить нельзя, а когда можно?

## Задача 5.5 ★★ Найди ошибки

*Уроки 27–28*

Программа должна напечатать массив, сумму его элементов, среднее и количество чётных элементов. Код компилируется,
но работает неправильно. Скопируй его в заготовку целиком, запусти, найди и исправь **пять** ошибок. Над каждой
исправленной строкой напиши в комментарии, что было не так.

```java
public static void main(String[] args) {
    int[] values = {3, 8, 5, 6, 1};

    printArray(values);
    System.out.println(getSum(values));
    System.out.println(getAverage(values));
    System.out.println(countEven(values));
}

public static void printArray(int[] values) {
    for (int value : values) {
        System.out.print(values + " ");
    }
    System.out.println();
}

public static int getSum(int[] values) {
    int sum = 0;
    for (int i = 1; i <= values.length; i++) {
        sum += values[i];
    }
    return sum;
}

public static double getAverage(int[] values) {
    return getSum(values) / values.length;
}

public static int countEven(int[] values) {
    int count = 0;
    for (int i = 0; i < values.length; i++) {
        if (i % 2 == 0) {
            count++;
        }
    }
    return count;
}
```

После исправления программа выводит:

```text
3 8 5 6 1
23
4.6
2
```
