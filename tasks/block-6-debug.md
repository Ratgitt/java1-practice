# Блок 6. Отладка

После урока 30. В каждой заготовке `src/block6/TaskXX.java` — готовая программа с ошибкой: компилируется,
но выводит не то. Найди ошибку **дебаггером** и исправь причину, а не подгоняй ответ под пример.

Приёмы из урока: breakpoint, Debug, Step Over, Step Into, Step Out, Resume, Frames и Variables, Evaluate Expression.
Шорткаты (Windows/Linux — macOS): breakpoint Ctrl+F8 — ⌘F8, Step Over F8, Step Into F7, Step Out Shift+F8 — ⇧F8,
Resume F9 — ⌥⌘R, Evaluate Alt+F8 — ⌥F8.

Перед отладкой посчитай на бумаге, какими должны быть значения, — иначе не с чем сверять Variables. Ответ — комментарием
внизу заготовки, номера строк — как в заготовке до исправления.

Решения пиши в заготовках `src/block6/TaskXX.java`.

## Задача 6.1 ★ Кофейня

*Урок 30*

Кофе — 180 рублей, круассан — 120. Вводится число кофе и круассанов. Если сумма от 1000 рублей, скидка 10 %.
Программа выводит, сколько заплатить.

**Пример 1**

```text
> 3
> 4
К оплате: 918
```

**Пример 2**

```text
> 2
> 1
К оплате: 480
```

Сейчас на примере 1:

```plain
> 3
> 4
К оплате: 920
```

В ответе: строка и значения переменных, где впервые расходится с бумагой; исправление.

## Задача 6.3 ★★ Три по цене двух

*Урок 30*

Акция «3 по цене 2»: из каждых трёх штук одного товара одна бесплатно (3 — платишь за 2, 4 — за 3, 2 — за 2).
Цены и количества четырёх товаров — массивы в программе. Программа выводит сумму к оплате.

```text

```

Сейчас:

```plain
К оплате: 700
```

Заходи в функции через Step Into, из правильно работающих выходи через Step Out. В ответе: при каком `i` и с какими
аргументами `getCost` впервые вернула неверное значение, какие фреймы были в Frames; исправление.

## Задача 6.4 ★★★ Ударный режим

*Урок 30*

Для каждого из четырёх учеников массив — минуты занятий по дням (0 — пропуск). Программа выводит самую длинную серию
дней подряд с занятиями.

```text
Ученик 1: 3
Ученик 2: 4
Ученик 3: 5
Ученик 4: 0
```

Сейчас:

```plain
Ученик 1: 3
Ученик 2: 1
Ученик 3: 0
Ученик 4: 0
```

Исправленная программа должна работать при серии в начале, в середине и в конце массива, а также без пропусков
и без занятий. В ответе: для ученика 2 — строка, `i`, `current` и `longest`, где впервые расходится; почему ученики 1
и 4 считаются верно; исправление.

## Задача 6.5 ★★★★ Симметричный массив

*Урок 30*

Функция `isSymmetric` проверяет, читается ли массив одинаково с обоих концов, как `{1, 2, 3, 2, 1}`. Массив из одного
элемента симметричен. Программа проверяет шесть массивов.

```text
Массив 1: true
Массив 2: true
Массив 3: false
Массив 4: false
Массив 5: true
Массив 6: false
```

Сейчас:

```plain
Массив 1: false
Массив 2: false
Массив 3: false
Массив 4: true
Массив 5: true
Массив 6: false
```

Ошибок **две**. Какие индексы сравниваются, проверяй через Evaluate Expression в точке остановки. В ответе: для
каждой ошибки — строка, массив и `i`; что выводит программа, если исправить только первую найденную, и почему.
