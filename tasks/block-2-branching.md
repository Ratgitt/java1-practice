# Блок 2. Ветвления

После уроков 11–16. Ты знаешь: `if`, `else`, `else if`, тернарный оператор `? :`, старый `switch` с `case`, `break`
и `default`, новый `switch` со стрелками `->` и switch, который возвращает значение в переменную. А ещё теперь можно
склеивать строки с числами: `System.out.println("Сумма: " + sum);`.

Важно для этого блока:

- **Циклов и своих функций ещё нет.** Каждая задача — один `main`, программа отвечает на один ввод. Чтобы проверить
  другой вариант — запусти программу ещё раз.
- **Тип переменной пиши явно** (`int`, `String`), без `var` — как советует автор.
- **Оформление — как в уроках 11–12:** класс лежит в пакете `block2` (заготовки уже там), перед сдачей код
  отформатирован (Ctrl+Alt+L или ⌥⌘L).
- **Ввод** — как в блоке 1, через `Scanner`. Слово читается `scanner.next()`, один символ — `scanner.next().charAt(0)`
  (см. README).

Решения пиши в заготовках `src/block2/TaskXX.java`.

## Задача 2.3 ★★ Предскажи вывод: ветвления и склейка

*Урок 13*

Скопируй код в `main` своей заготовки, после строки со `Scanner`. **Не запуская**, напиши в комментарии,
что программа выведет, если ввести `7`, потом `20`, потом `0`, потом `-3`. Затем запусти четыре раза и сверь.
Где ошибся — допиши, почему на самом деле так.

```java
int x = scanner.nextInt();

if (x > 0) {
    System.out.println("плюс");
}
if (x > 10) {
    System.out.println("больше 10");
} else if (x > 5) {
    System.out.println("больше 5");
} else {
    System.out.println("не больше 5");
}

if (x % 2 == 1) {
    System.out.println(x + " нечётное");
} else {
    System.out.println(x + " чётное");
}

String size = x > 10 ? "большое" : "маленькое";
System.out.println(size);

System.out.println("x + 1 = " + x + 1);
System.out.println(x + 1 + " = x + 1");
```

Ответь в комментариях ещё на два вопроса:

1. Одна из строк выводит неправду для некоторых чисел. Какая и для каких? Как её исправить?
2. Как поправить предпоследний `println`, чтобы для `7` он выводил `x + 1 = 8`?

## Задача 2.6 ★★ Предскажи вывод: switch без break

*Уроки 14–15*

**Часть А.** Скопируй код в `main` после строки со `Scanner`. **Не запуская**, напиши в комментарии, что программа
выведет для `1`, `2`, `3`, `4`, `5` и `0`. Потом проверь запусками и объясни расхождения.

```java
int code = scanner.nextInt();
int points = 0;
switch (code) {
    case 1:
        points += 10;
    case 2:
        points += 20;
        break;
    case 3:
    case 4:
        points += 5;
    default:
        points += 1;
}
System.out.println("Очки: " + points);
```

**Часть Б.** Перепиши этот `switch` на новый, со стрелками, — так, чтобы он возвращал число очков в переменную:
`int points = switch (code) { … };`. Программа должна выводить то же самое, что и старая, для **любого** числа.
Старый вариант закомментируй.

## Задача 2.7 ★★ Калькулятор

*Уроки 14–15*

Пользователь вводит целое число, знак операции и ещё одно целое число — каждое на своей строке.
Знак — один символ: `+`, `-`, `*`, `/` или `%`. Деление — целочисленное, как в блоке 1.
Выведи пример целиком с ответом.

Выбери операцию через `switch` по символу (`char`). В уроке `switch` писали только по числам, но автор сказал,
что `char` тоже можно, — это и попробуй. Символ в `case` пишется в одинарных кавычках, как любой `char`: `case '+'`.

Особые случаи:

- на ноль делить нельзя — программа упадёт с ошибкой. Поэтому для `/` и `%` при втором числе 0 выведи
  `На ноль делить нельзя`;
- если знак не из списка — выведи `Неизвестная операция: ` и сам знак.

**Пример 1**

```text
> 17
> /
> 5
17 / 5 = 3
```

**Пример 2**

```text
> 7
> -
> 10
7 - 10 = -3
```

**Пример 3**

```text
> 8
> %
> 0
На ноль делить нельзя
```

**Пример 4**

```text
> 2
> ^
> 3
Неизвестная операция: ^
```

## Задача 2.9 ★★ Найди ошибки

*Уроки 13–15*

В этом коде пять ошибок — он не компилируется. Скопируй его в `main`, найди ошибки (IDEA подчеркнёт их красным)
и исправь каждую, сохранив смысл программы.

```java
int temperature = 25;
long dayNumber = 3;

if (temperature = 25) {
    System.out.println("Ровно 25 градусов");
}

String weather;
if (temperature > 20) {
    weather = "тепло";
} else if (temperature < 0) {
    weather = "мороз";
}
System.out.println("На улице " + weather);

switch (dayNumber) {
    case 6, 7 -> System.out.println("Выходной");
    default -> System.out.println("Будний день");
}

int place = 2;
String medal = switch (place) {
    case 1 -> "золото";
    case 2 -> "серебро";
    case 3 -> "бронза";
}
System.out.println("Медаль: " + medal);
```

Над каждой исправленной строкой напиши в комментарии, что сообщила IDEA и почему это ошибка.

После исправлений программа выводит:

```text
Ровно 25 градусов
На улице тепло
Будний день
Медаль: серебро
```
